# topip — 边缘安全网关 Top-50 源 IP 统计组件

纯内存实现近 24 小时（`now` 所在分钟 + 之前 1439 个完整分钟）被拦截次数最多的
50 个源 IP。进程重启后统计清零。

## 接口

```go
tr := topip.NewTracker()
tr.Record(ip, ts)   // 每拦截一个请求调用一次，并发安全
items := tr.Top(now) // 至多 50 个 Item{IP, Count}，按计数降序
```

- `Record(ip, ts)`：`ts` 为 Unix 秒，允许最多比此前最大 `ts` 小 2 分钟
  （乱序迟到），迟到记录计入其所属分钟；更早的记录丢弃。
- `Top(now)`：`now` 单调不减且不小于任何已记录的 `ts`，可与 `Record` 并发。

## 设计

- **每分钟一个 Space-Saving 摘要**（`slot.go`）：每个分钟槽固定 1000 个计数器。
  新地址在槽满时驱逐最小计数器并以 `min+1` 接管。单分钟误差 ≤ 该分钟记录数/1000，
  1440 分钟求和后总误差 ≤ N/1000（N 为窗口拦截总数）。分钟槽内的哈希索引、
  最小堆全部为定长数组，记录路径零分配。
- **全局聚合表**（`agg.go`）：2^21 槽的开放寻址哈希表，增量维护
  「IP → 各分钟估计值之和」。分钟过期时逐条目精确扣减（backward-shift 删除），
  因此窗口边界精确到分钟，过期数据立即消失而非衰减。聚合表按 256 槽分块缓存
  块内最大值，`Top` 先用第 50 大的块最大值做阈值跳过不可能的块。
- **分钟环**（`tracker.go`）：2048 槽环形数组保存最近 ≤1440 个分钟槽，
  迟到记录按所属分钟直接落槽；窗口滑动由 `Record`（新分钟到来）和
  `Top`（`now` 前进）共同驱动。

三条保证（对任意输入序列确定成立，非概率）：

1. 返回计数与真实计数之差 ≤ N/1000（估计恒 ≥ 真实，误差只来自 Space-Saving 接管）。
2. 真实计数 > t50 + N/500 的 IP 必然出现（否则将有 50 个 IP 真实计数都 > t50，矛盾）。
3. 结果中每个 IP 真实计数 ≥ t50 - N/500（估计逐点 ≥ 真实，故第 50 大估计 ≥ t50）。

内存与不同地址数无关：分钟槽 1440 × ~36 KiB + 聚合表 ~50 MiB，
实测满窗口 GC 后堆占用 ≈ 105 MiB（上限 192 MiB）。

## 测试与基准

```sh
go test ./...            # 正确性：洪水对照、窗口边界、迟到、内存上限
go test -run '^$' -bench . -benchtime 1s .
```

- `TestFloodAccuracy`：1030 万次拦截、26 小时跨度，750 万个一次性伪造地址中
  混 65 个强度不一、部分仅在特定时段活跃的打击者，在 5 个 `now` 上逐条核对三条保证。
- `TestWindowBoundary`：窗口最早一分钟内的最强打击者必须命中且计数满足误差界；
  再早一分钟的最强打击者必须消失。
- `TestLateArrival`：整点前后迟到 60s/120s 的记录计入正确分钟，并随该分钟一起过期。
- `TestMemoryBound`：满窗口（每分钟 1100 个不同地址）下断言堆占用 < 192 MiB。

基准（Apple M1 Max）：最坏输入（每条都是新地址）Record ≈ 1.7M/s；
满窗口跨分钟边界 Record 最大单次 ≈ 0.9 ms；满窗口 Top 最大单次 ≈ 7.3 ms
（重尾流量下因块最大值剪枝远低于此）；堆占用 ≈ 105 MiB。
